### 💡 关于本项目
小暖是一个专注于家庭事务管理的智能 Agent 系统。它能够：
- **智能对话**：像家人一样交流，记住家庭细节。
- **排程管理**：自动调度提醒、作业和日常任务。
- **多端联动**：在桌面、Pad 陪伴屏之间实现无缝信息流转。

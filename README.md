## 📖 关于小暖 (XiaoNuan)

小暖是一款基于 **本地优先（Local-First）** 架构打造的家庭智能管家与伴学管家。她不是一个冰冷的网页聊天机器人，而是一个静默在后台、深度融入您家庭真实生活的智能中枢。

全家对话、相册照片、日历待办、见闻手账、家庭纪念日与账本数据 **100% 保存在您本地的硬盘与数据库中**，核心隐私数据绝不上传云端，隐私主权完全属于家庭。

## ✨ 核心能力与特性

- 🧠 **家庭 Agent 伴学伴读**：话题会话、技能调用（`/` 快捷指令），研读文章并一键剪藏归档。
- 🌅 **家庭见闻手账**：朝闻天下、暮省一日，外闻与家事每天扫一眼即可心中有数。
- 🗓️ **家庭日历与纪念日**：日程、行程、网购、节气与家庭重要纪念日叠在一张月历上。
- ✅ **全家待办看板**：按周展开的家庭看板，工作与家事分栏推进。
- 📷 **本地时光相册与知识库**：按时光轴记录生活，照片不进别人的云；Wiki 结论对接 Obsidian。
- 🛠️ **开放模型生态**：支持一键接入 华为 MaaS、DeepSeek、阿里云百炼、火山引擎、Moonshot Kimi、智谱 GLM 与本地 Ollama。
